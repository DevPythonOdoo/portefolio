📋 Instructions de téléchargement :

  2. Le téléchargement commencera automatiquement
  3. Extrayez l'archive ZIP sur votre ordinateur

  5. Suivez le guide de personnalisation pour adapter le contenu
⚠️ Important : Ce portfolio utilise des API RESTful pour la base de données. En production, vous devrez configurer un serveur backend ou utiliser des services tiers pour certaines fonctionnalités.

  1. Personnalisez votre photo via `upload-photo.html`

  3. Utilisez l'onglet Publish pour le mettre en ligne
  4. Ou déployez sur GitHub Pages, Netlify, ou Vercel
