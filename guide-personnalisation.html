🎯 Guide de Personnalisation

Personnalisez votre portfolio Expert Odoo en quelques étapes simples

1. 📸 Ajouter votre photo professionnelle

1 Option recommandée : Formulaire d'upload

Ouvrez upload-photo.html et suivez les instructions pour uploader votre photo.

Uploader ma photo
2 Option alternative : Remplacement direct

Remplacez le fichier images/ma-photo-profil.jpg par votre photo.

3 Rappel de la pose :
  • Bras reposant sur le dossier d'une chaise
  • Pieds croisés de manière naturelle
  • Expression professionnelle et accueillante

2. 📝 Personnaliser vos informations

1 Titre et méta-informations
<title>Expert Odoo - Votre Nom - Développement & Formation ERP</title> <meta name="description" content="Expert Odoo certifié - Votre spécialité"> <meta name="author" content="Votre Nom">
2 Section Hero (lignes 54-61)
<h1 class="hero-title"> Développement & Personnalisation <span class="highlight">Odoo</span> sur Mesure </h1> <p class="hero-description"> Je transforme votre système de gestion intégré en solution d'entreprise puissante. Expert en développement, personnalisation de modules et formation ERP Odoo. </p>
3 Coordonnées de contact (lignes 390-409)
<p>contact@votre-domaine.fr</p> <p>+33 6 XX XX XX XX</p> <p>Votre ville - Disponible à distance</p>

3. 🎨 Personnaliser les couleurs

Modifiez les variables CSS dans css/style.css :

:root { /* Vos couleurs personnalisées */ --primary-orange: #ff6b35; /* Votre orange */ --primary-blue: #1565c0; /* Votre bleu */ --primary-black: #0a0a0a; /* Votre noir */ }

4. 📊 Ajouter vos projets

Ajoutez vos projets via l'API RESTful ou modifiez directement dans js/portfolio.js

Voir mon portfolio

5. 🚀 Déployer votre site

Une fois personnalisé, rendez-vous sur l'onglet Publish pour mettre votre site en ligne !
